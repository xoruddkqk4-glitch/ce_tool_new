## 1. 개요 및 배경

### 1.1 사용자 문제 제기
1. **1단계 시간 배지(⏱) 수치 입력의 한계**: 
   - 문장 카드의 `⏱` 배지를 클릭하여 `prompt()` 창에서 초 단위 숫자(예: `3.5 ~ 8.2`)를 직접 입력하는 방식은 파형 시각 정보가 없어 음성이 시작되고 끝나는 지점을 눈으로 확인할 수 없음.
2. **2단계 A-B 루프 기능의 목적 불일치**: 
   - 2단계 파형 플레이어는 이미 분류된 단일 문장의 구간 내에서 줌인하여 반복 훈련하기 위한 기능으로, 전체 프로젝트의 문장별 타임스탬프(`audioStart`, `audioEnd`) 경계를 재분류하는 용도로는 부적합함.
3. **제안**: 
   - 1단계 입력 화면에 전체 오디오 파형 그래프를 보여주고, 문장별 구간을 마우스로 보면서 직접 선택 및 미세 조정할 수 있는 기능 추가.

## 3. 세부 기능 명세

### 3.1 [컴포넌트 1] 마스터 오디오 파형 타임라인 (`MasterWaveformTimeline`)
- **표시 위치**: 1단계 `audioUploadSection` 바로 아래 또는 `parsedResultsSection`의 문장 목록 상단
- **표시 조건**: MP3 음성 파일이 업로드되어 `appState.audioBuffer`가 존재할 때 자동 활성화
- **기능**:
  1. **전체 파형 렌더링**: 전체 오디오의 PCM 피크 데이터를 Canvas에 축약 렌더링
  2. **문장 세그먼트 오버레이**: `sentenceList`의 각 문장별 구간(`audioStart` ~ `audioEnd`)을 컬러 박스와 S1, S2, S3 태그로 시각화
  3. **드래그 리사이즈 핸들 (Boundary Resizing)**:
     - 문장 블록 사이의 경계 바를 마우스로 잡고 좌우로 드래그하면, 시작/종료 시간이 실시간 업데이트
     - VAD 감지 무음 구간(Silence) 근처로 드래그 시 자석처럼 달라붙는 **스냅(Snap) 가이드** 제공
  4. **클릭 즉시 청취**: 세그먼트 클릭 시 해당 문장 구간만 재생하여 귀로 확인 가능
  5. **스크롤 동기화**: 세그먼트를 더블클릭하면 하단의 해당 문장 카드로 부드럽게 스크롤 이동

### 3.2 [컴포넌트 2] 문장 카드별 파형 트리머 (`SentenceWaveformTrimmerModal`)
- **실행 방식**: 문장 카드의 `⏱ 시간 배지` 클릭 시 기존 브라우저 `prompt()` 대신 모달 또는 인라인 드로어로 열림
- **기능**:
  1. 현재 문장 시작점 앞 1.5초 ~ 끝점 뒤 1.5초 구간을 고해상도로 줌인하여 파형 표시
  2. 좌측 핸들(시작점), 우측 핸들(끝점)을 드래그하여 0.05초 단위 미세 조정
  3. 단축키 스페이스바로 선택 영역 즉시 반복 청취
  4. [저장] 클릭 시 문장 데이터에 즉시 반영 및 2단계 캐시 자동 무효화/갱신

## 5. 예상 효과 및 검증 시나리오

1. **직관적인 싱크 보정**: 안내 멘트나 음악으로 인해 앞부분이 밀렸을 때, 마스터 파형을 보면서 S1 블록을 시작 지점으로 끌어다 놓기만 하면 2초 만에 완벽한 싱크를 맞출 수 있음.
2. **시각적 오류 방지**: 말이 끊어지지 않고 이어지는 부분을 눈으로 보면서 경계를 나눌 수 있어 단어가 잘리는 현상 원천 차단.
3. **완전 독립형 유지**: 추가 외부 라이브러리(wavesurfer.js 등) 없이 기존 Web Audio API와 순수 Canvas 2D로 경량 구현하여 빌드 크기 및 성능 최적화 유지.
